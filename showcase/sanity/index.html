Content Lake

Query content
like a database

GROQ is a query language built for JSON — projections, joins and filters that run in milliseconds against a globally replicated Content Lake with realtime updates.

Read the GROQ docs →
groq — featuredPosts.query12 ms
import { createClient } from "next-sanity"

export const client = createClient({
  projectId: "pv8y60b",
  dataset: "production",
  perspective: "published",
})

const posts = await client.fetch(`
  *[_type == "post" && featured == true]{
    title, slug, author->{name},
    "publishedAt": coalesce(date, _createdAt)
  } | order(publishedAt desc)[0...5]
`)
// streamed live to every open tab
