Platform

Everything you need
in one backend

Postgres database

A dedicated Postgres instance with row-level security, extensions, and full SQL — no abstractions between you and your data.

create policy "own rows"
using (auth.uid() = user_id);

Authentication

Email, OAuth, magic links, and SSO out of the box. Users live in your own database, so joins and policies just work.

supabaze.auth.signInWithOAuth({
  provider: 'github'
})

Instant APIs

Every table introspected and served over REST and GraphQL with realtime subscriptions — generated, versioned, documented.

const { data } = await db
  .from('events')
  .select('*')
